# Directrices del Proyecto

## Acceso a Archivos y Web

- **Lectura global:** Puedes consultar (modo solo lectura) archivos en cualquier ubicación de este ordenador cuando sea necesario.

- **Escritura restringida:** NUNCA alteres, modifiques ni crees ningún archivo fuera de la carpeta de este proyecto.

- **Búsqueda de información:** Cuando te falte información, búscala en internet. Si no encuentras lo que buscas, pregúntaselo al usuario. NUNCA deduzcas ni asumas algo si no estás completamente seguro de ello.

## Git y GitHub

- Gestionarás de forma autónoma Git y GitHub (push, merge, etc...).

## Ventana de contexto

Cuando la ventana de contexto llegue al 80%, para con la tarea actual y crea un prompt detallado para continuar con la tarea desde una nueva conversación.

## Plan de Implementación

Utiliza el archivo .PLANNING.md como referencia para el control de tareas. Cada vez que realices total o parcialmente una tarea, o altere tareas ya realizadas, actualiza el estado de la tarea en el archivo .PLANNING.md. En la columna "Comentarios" del archivo .PLANNING.md, anota que has realizado la tarea y cualquier comentario relevante.

## Criterio de elección de tarea a realizar

Con base al archivo .TAREAS.md reanuda el desarrollo del proyecto mirando las tareas no finalizadas. Elige con cual trabajar en función de lo que la lógica de desarrollo tenga sentido. Siempre usando el mcp REA cuando sea necesario.

## Lenguaje de programación
Tras evaluar el programa fuente del clon, aconsejame entre C++ o Rust.

## Calidad
Asegúrate de que todas las funciones son clonadas, excepto si el usuario te pide explicitamente excluir determinadas funciones o características
